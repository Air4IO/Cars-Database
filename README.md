# AIR-4 AC Cleaning Case Log

Single-file React app for logging and presenting car AC evaporator cleaning cases.

## Run

Open `index.html` in a browser. The app loads React, Tailwind CSS, Font Awesome, and Babel from public CDNs, then stores case data in the browser's `localStorage`.

## Notes

- Admin/customer modes are selected from the in-app login dialog.
- Data saved in one browser is local to that browser.
- Internet access is required for CDN scripts, fonts, icons, and sample images.
